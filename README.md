# Gemini 默认模型选择器

[English](README_EN.md)

一个轻量的 Tampermonkey/Violentmonkey 用户脚本。它会在你进入 Gemini 新对话首页时，自动选择预先设定的默认模型与思考等级。

## 功能

- 自动读取 Gemini 当前展示的模型列表，不依赖固定版本号。
- 支持 3.5 Flash-Lite、3.8 Flash、3.1 Pro、4 Argon，以及 Gemini 后续展示的其他模型。
- 支持新版三档“思考等级”选择：**低（快速高效）**、**中（深度适中）**、**高（超级详尽）**。
- 默认设置为 **3.8 Flash + 高思考等级**。
- **前置静默就绪**：首屏加载即在 0.2 秒内自动切换到位，精准区分原生对焦与实际输入；打完 Prompt 敲一次回车即可正常发送，无需二次确认。
- **双重提交重放保障**：如果发生极速提交拦截，采用完整的 Pointer 与键盘事件组合重发，绝不丢失输入或需要二次回车。
- **自由拖拽定位**：“默认模型”悬浮胶囊支持鼠标与触屏自由拖拽并持久化记住位置，不再遮挡页面内容。
- 深度兼容 Gemini 网页版最新启用的 **Trusted Types (CSP)** 规范。
- 同时兼容 `gemini.google.com/app` 与 `gemini.google.com/u/0/app` 等多账号地址。
- 仅在新对话首页自动应用，不会强行修改已有对话的模型。
- 设置保存在用户脚本管理器本地，不会发送到任何服务器。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)。
2. [点击这里安装脚本](https://raw.githubusercontent.com/B416-JAFLY/gemini-default-model-selector/main/gemini-default-model-selector.user.js)。
3. 打开 Gemini，新对话页面会自动应用默认设置。

## 修改默认设置

有两种入口：

- 点击 Gemini 页面右下角的“默认模型”悬浮胶囊按钮（按住可拖动位置，单击打开设置）。
- 打开用户脚本管理器菜单，选择“设置 Gemini 默认模型”。

在面板中选择默认模型和思考等级，然后点击“保存并立即应用”。模型列表会从当前 Gemini 页面动态读取，因此 Gemini 更新模型版本号后通常不需要更新脚本。

## 输入焦点保护与前置就绪

Gemini 首页加载时会自动聚焦到空输入框。脚本能精确辨析“空输入框原生聚焦”与“用户正在输入文字”：
- 当输入框为空且未敲击按键时，脚本在后台闪电完成默认模型与思考等级设定，并无缝归还光标；
- 当用户正在输入或已输入内容时，脚本会暂停操作，避免菜单抢夺焦点；
- 即使在未完全就绪前极速提交，脚本也会在补齐切换后通过底层事件组合全自动重放提交，无需二次敲击回车。

## 关于“思考等级”

Gemini 网页版已将原有的“扩展思考”升级为三级可调的“思考等级”菜单（低、中、高）。本脚本已全面跟进该架构，可直接对二级菜单进行自动化切换与状态追踪。

## 开发与检查

项目不依赖第三方包。克隆后可运行：

```bash
npm run check
```

该命令会检查用户脚本的 JavaScript 语法。
